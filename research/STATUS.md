# 🔬 PrismChain Research — Status

> **The documentation should describe the state of knowledge, not the desired state of the project.**

This document provides the current public status of research across the PrismChain ecosystem.

Its purpose is to distinguish:

* what is established;
* what has been demonstrated;
* what is actively being researched;
* what is experimental;
* what remains hypothetical;
* what is historical;
* and what is intentionally private.

Research status is not a marketing score.

It is a statement about the current state of knowledge and evidence.

---

# 1. Status Vocabulary

The PrismChain ecosystem uses the following public status categories.

| Status                      | Meaning                                                                                   |
| --------------------------- | ----------------------------------------------------------------------------------------- |
| 🟢 **Built / Demonstrated** | Supported by implementation, testing, or other documented evidence within a defined scope |

| ⚪ **Historical**            | Earlier research preserved for intellectual lineage                                       |
| 🔴 **Private**              | Intentionally undisclosed research or implementation                                      |

These labels describe the status of the **specific subject being discussed**.

They do not automatically describe the entire ecosystem.
